01_ACADEMIC

Purpose

This department contains formal academic and university-related work.

It is the dedicated school/university workspace of the Life OS.

What belongs here

- Course notes
- Assignments
- Continuous assessment tests (CATs)
- Examination preparation and records
- Academic projects
- Academic reports and presentations
- Supporting academic reference material

Structure

01_ACADEMIC/
├── 01_NOTES/
├── 02_ASSIGNMENTS/
├── 03_CATS/
├── 04_EXAMS/
└── 05_PROJECTS/

Operating principle

Academic material should follow the academic lifecycle:

LEARN → NOTE → PRACTICE → SUBMIT → REVIEW → ARCHIVE

Git principle

Track useful text, source files, code, reports, documentation and reproducible academic work.

Avoid committing credentials, private records, unnecessary generated files or sensitive personal information.
