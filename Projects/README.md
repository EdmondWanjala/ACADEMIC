# ACADEMIC — PROJECTS

## Purpose

This folder contains projects completed specifically as part of formal
academic study.

## Contains

- Course projects
- Semester projects
- Group projects
- Final-year projects
- Academic engineering projects
- Academic software projects
- Project reports
- Project documentation
- Project presentations
- Supporting research and files

## Organization

Each academic project should have its own project folder.

Where appropriate, organize projects by course, semester, academic year,
or project type.

## Scope

Only school/university-related projects belong here.

Standalone personal and technical projects belong in 06_PROJECTS.
