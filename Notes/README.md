# ACADEMIC — NOTES

## Purpose

This folder contains notes and learning material created or collected as
part of formal academic study.

## Contains

- Lecture notes
- Personal study notes
- Summaries
- Worked examples
- Revision notes
- Course references
- Diagrams and explanations
- Subject-specific learning material

## Organization

Organize notes according to the relevant course, subject, semester, or
academic period.

## Scope

Only formal school/university learning material belongs here.

Independent technical studies belong in 07_TECHNICAL_STUDIES.
